# 個人財務深層分析儀表板

這是一個專為 Google Sheets 設計的自動化財務分析與儀表板系統。透過 Google Apps Script 將試算表中的記帳資料即時視覺化，協助您有效管理資產並分析消費習慣。

## 主要功能

* **財務指標儀表板**：快速查看當前總資產、實質總收入、個人實質純支出以及飲食開銷。
* **即時視覺化圖表**：

  * **消費類別佔比**：透過圓餅圖分析各項支出的分佈。
  * **帳戶結餘分析**：透過柱狀圖檢視各個帳戶的最新結餘情況。
* **互動式流水帳明細**：

  * 提供完整的交易紀錄表格。
  * 支援關鍵字搜尋（項目說明、備註）。
  * 支援分類標籤與帳戶類別篩選。
* **完全整合 Google Workspace**：利用 `google.script.run` 直接串接 Google Sheets 資料，無需額外的後端伺服器，資料隱私更有保障。

## 技術架構

* **前端 (index.html)**：採用 Tailwind CSS 打造現代化響應式介面，使用 Chart.js 進行資料繪圖，並整合 Lucide Icons 提供直觀的 UI 圖示。
* **後端 (Code.gs)**：使用 Google Apps Script 自動讀取並處理「記帳資料」試算表中的數值，轉換為前端可讀的 JSON 格式。

## 如何部署

1. 在您的 Google Sheets 中，點選 `擴充功能` > `Apps Script`。
2. 建立 `Code.gs` 並貼上後端程式碼。
3. 建立 `index.html` 並貼上前端介面程式碼。
4. 點選「部署」>「新增部署」>「網頁應用程式」。
5. 將存取權限設定為「只有我自己」（確保安全性）。
6. 部署完成後，即可透過專屬網址存取您的財務儀表板。

## 資料格式要求

本儀表板預設讀取名為「記帳資料」的工作表，請確保您的試算表欄位如下：

1. 日期
2. 時間
3. 支付帳戶
4. 項目說明
5. 分類標籤
6. 交易金額
7. 備註細節
